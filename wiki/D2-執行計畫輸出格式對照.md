# D2 — 三引擎執行計畫輸出格式對照

**來源**：S2, S4, S10, S11
**⚠ 版本相依條目：引用時必須標明引擎。**

| | PostgreSQL 18 | MySQL 8.0 | SQLite |
|---|---|---|---|
| 指令 | `EXPLAIN` / `EXPLAIN ANALYZE` [S2] | `EXPLAIN` / `EXPLAIN FORMAT=JSON` [S10] | `EXPLAIN QUERY PLAN` [S11] |
| 輸出形式 | 計畫節點樹，一節點一行，縮排表示層次 [S2] | 表格，一列一張表 [S10] | 高階概觀 [S11] |
| 是否實際執行 | `EXPLAIN` 不執行；`EXPLAIN ANALYZE` 執行 [S2] | `EXPLAIN` 不執行 [S10] | 不執行 [S11] |
| 成本表示 | `cost=startup..total rows=N width=W`，任意單位 [S2] | 無成本欄位；以 `rows`、`filtered` 表示估計 [S10] | 本次來源未提供 |
| 「沒用索引」的訊號 | `Seq Scan` 節點 [S2] | `type: ALL`，`key: NULL` [S10] | 輸出中顯示全表掃描 [S11] |
| 「用了覆蓋索引」的訊號 | `Index Only Scan` 節點 [S4] | `Extra: Using index` [S10] | 本次來源未提供 |
| 實際 vs 估計 | `EXPLAIN ANALYZE` 同時顯示兩者 [S2] | 僅估計；需自行比對真實列數 [S10] | 本次來源未提供 |

## 教學用途

此條目用於支撐簡報中「如何自己看出查詢有沒有用到索引」那一頁。
**該頁必須只示範一個引擎**（選 SQLite，因為可實跑驗證），並明確標示其他引擎的指令不同。
